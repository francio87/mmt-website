# Marmitte dei Giganti

Sito informativo sulle Marmitte dei Giganti di San Lazzaro, Fossombrone: [marmittedeigiganti.com](https://marmittedeigiganti.com).

## Sviluppo

```bash
npm ci
npm run dev
```

## Pubblicazione

Ogni push su `master` pubblica il sito. Gli altri branch generano un'anteprima, linkata nella pull request.
